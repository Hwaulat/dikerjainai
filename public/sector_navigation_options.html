UI/UX Architecture Review

Pilihan Model Tampilan Menu Per Sektor

Pilih salah satu dari 4 model navigasi modern di bawah untuk diterapkan ke Dashboard Kefir Derma Clinic.

Model 1 Gaya Slack / Discord / Linear

Two-Tier Double Rail (Icon Strip + Dynamic Panel)

Sidebar dibagi menjadi 2 layer: strip icon tipis (64px) di sisi paling kiri untuk memilih sektor (Doctor, HR, Ops, dll), dan panel kedua (220px) yang hanya menampilkan modul-modul milik sektor tersebut.

Kelebihan Model Ini:
  • Fokus Penuh: Layar bersih, staf dokter hanya melihat menu medis tanpa terdistraksi HR/Finance.
  • Akses 1 Klik: Pindah sektor instan cukup klik icon di rail kiri.
  • Standar SaaS Modern: Digunakan oleh aplikasi kelas enterprise seperti Slack, Notion Workspace, dan Discord.
Mau pilih model ini untuk diterapkan ke dashboard?
Ringkasan 4 Pilihan:
1. Two-Tier
Double rail icon + sub-panel
2. Top Bar
Tab sektor di atas, isi di samping
3. Accordion
Bisa expand/collapse per sektor
4. App Switcher
Dropdown workspace di pojok

Pratinjau Model Two-Tier:

EXECUTIVE MENU

Tampilan Menu Sektor di Atas Layar

Horizontal Sector Switching

Pada model ini, sektor berpindah secara horizontal di bilah atas (top navbar), mirip seperti berpindah divisi di dashboard Linear atau Google Cloud Console. Sidebar kiri hanya memuat modul dari sektor yang sedang aktif.

KEFIR DERMA

COLLAPSIBLE TREE

Tampilan Accordion / Collapsible Tree

Expandable Sidebar

Di model ini, semua sektor berada di sidebar tunggal namun dalam bentuk accordion (bisa diklik untuk buka/tutup). Secara default, hanya 1 sektor yang terbuka sehingga sidebar tidak memanjang ke bawah dan terlihat rapi seperti folder tree.
